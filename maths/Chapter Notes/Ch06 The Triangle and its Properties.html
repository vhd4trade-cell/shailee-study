00પ્રકરણ એક નજરે

શા માટે ભણવું: ત્રિકોણ સૌથી મજબૂત આકાર છે (પુલ, છાપરાં, નિસરણી). આ પ્રકરણમાં ત્રિકોણ વિશે ખાતરીથી કહી શકાય એવા ગુણધર્મો શીખીએ — ખૂણાનો સરવાળો 180° અને કાટકોણમાં a² = b² + c².

આ પ્રકરણ પછી તમે (1) મધ્યગા અને વેધ દોરી-ઓળખી શકશો, (2) બહિષ્કોણનો ગુણધર્મ અને ખૂણાના સરવાળાનો ગુણધર્મ વાપરી શકશો, (3) સમબાજુ-સમદ્વિબાજુના ખૂણા કહી શકશો, (4) ત્રણ લંબાઈથી ત્રિકોણ બને કે નહિ તે નક્કી કરી શકશો, (5) પાયથાગોરસનો ગુણધર્મ વાપરી શકશો.
શબ્દોનો પાયોત્રિકોણ = ત્રિ (ત્રણ) + કોણ (ખૂણો) → ત્રણ ખૂણાવાળો આકાર; ત્રણ બાજુ, ત્રણ શિરોબિંદુ (શિર = ટોચ). મધ્યગા = મધ્ય (વચ્ચેના બિંદુ) સુધી ગતિ કરતો રેખાખંડ. વેધ = વીંધીને પસાર થતો (લંબ) → ઊંચાઈ. બહિષ્કોણ = બહિ (બહાર) + કોણ → બહારનો ખૂણો; અંતઃસંમુખકોણ = અંદરના, સામેના (remote interior). સમબાજુ = સમ (સરખી) બાજુઓ; સમદ્વિબાજુ = સમ + દ્વિ (બે) બાજુ → બે બાજુ સરખી. કર્ણ = કાટખૂણાની સામેની સૌથી લાંબી બાજુ; પાયો = કાટખૂણો બનાવતી બે બાજુ. ગુણધર્મ = ગુણ + ધર્મ → તે આકારનો સ્વભાવ. પ્રમેય = સાબિત થયેલો નિયમ.
આકૃતિ 1 — ΔABC (પાન 86): 3 બાજુઓ AB, BC, CA; 3 ખૂણાઓ; 3 શિરોબિંદુઓ A, B, C. શિરોબિંદુ A ની સામેની બાજુ BC. (બાજુઓ 6, 8, 5 સેમી — અમારું ઉદાહરણ.)
આકૃતિ 2 — બાજુ પ્રમાણે: વિષમબાજુ (ત્રણેય જુદી), સમદ્વિબાજુ (બે સરખી), સમબાજુ (ત્રણેય સરખી). ખૂણા પ્રમાણે: લઘુકોણ, કાટકોણ, ગુરુકોણ. સરખી બાજુ પર સરખા ટપકાં (ટિક).
આકૃતિ 3 — આખા પ્રકરણનું સારાંશ-ચિત્ર: હરોળ = ખ્યાલ; સ્તંભ = શું / યાદ રાખવાની વાત.
રોજિંદું ઉદાહરણછાપરાંનો ત્રિકોણ આકાર, પુલના ગર્ડર, સાયકલની ફ્રેમ, નિસરણી — ત્રિકોણ આકાર ન બદલાય, તેથી મજબૂત. ચાર સળિયાનો ચોરસ વાંકો થઈ શકે, ત્રણનો ત્રિકોણ નહિ.
સામાન્ય ભૂલ"સમદ્વિબાજુ એટલે બે સરખા ખૂણા" — ખૂણા પણ સરખા હોય, પણ વ્યાખ્યા બે બાજુ સરખી (પાન 96). સમબાજુમાં ત્રણેય બાજુ સરખી.

01મધ્યગા અને વેધ

શા માટે ભણવું: બે ખાસ રેખાખંડ — શિરોબિંદુમાંથી સામેની બાજુ તરફ (પાન 87–88).

1a. મધ્યગા (Median)

કાગળ વાળીને BC નું મધ્યબિંદુ D શોધો. શિરોબિંદુ A ને D સાથે જોડતો રેખાખંડ AD = મધ્યગા. મધ્યગા ત્રિકોણના શિરોબિંદુને તેની સામેની બાજુના મધ્યબિંદુ સાથે જોડે છે. ત્રણેય બાજુ માટે ત્રણ મધ્યગા.

આકૃતિ 4 — લઘુ, કાટ અને ગુરુકોણ ત્રિકોણમાં ત્રણ-ત્રણ મધ્યગા. બિંદુ = સામેની બાજુનું મધ્યબિંદુ (માપ કરીને સરખું અંતર). દરેક મધ્યગા ત્રિકોણની અંદર રહે છે.
યાદ રાખવું
મધ્યગા: શિરોબિંદુ → સામેની બાજુનું મધ્યબિંદુ · ત્રણ મધ્યગા
આકૃતિ 4 માં ત્રણેય મધ્યગા એક જ બિંદુએ મળતી દેખાય છે — એ પુસ્તકમાં નથી (વધારાનું અવલોકન).

1b. વેધ (Altitude)

ત્રિકોણ આકારનું પૂઠું ટેબલ પર ઊભું મૂકો. શિરોબિંદુ A થી આધાર BC સુધીનું અંતર = ઊંચાઈ. A થી BC પર લંબ રેખાખંડ AL = વેધ. વેધનો એક અંતિમબિંદુ શિરોબિંદુ અને બીજો સામેની બાજુને સમાવતી રેખા પર. દરેક શિરોબિંદુએથી વેધ દોરી શકાય — ત્રણ વેધ.

આકૃતિ 5 — વેધ (ઘાટા ચટ્ટા ટપકાં). લઘુકોણ: ત્રણેય અંદર. કાટકોણ: કાટખૂણાથી શરૂ થતો વેધ અંદર; બાકીના બે વેધ ત્રિકોણની બે બાજુ જ. ગુરુકોણ: બે વેધ બહાર, બાજુની લંબાવેલી રેખા (ટપકાંવાળી) પર ઊતરે.
રોજિંદું ઉદાહરણદીવાલની ઊંચાઈ માપવા ટેપ ઊભી લટકાવો — દોરી ભૂમિ પર લંબ = વેધ. ત્રિકોણના ક્ષેત્રફળમાં "ઊંચાઈ" આ જ વેધ (પછીનાં પ્રકરણોમાં).
વિચારો, ચર્ચા કરો (પુસ્તક)
  1. કોઈ પણ ત્રિકોણને કેટલી મધ્યગા? એક ત્રિકોણના કેટલા વેધ?
  2. શું આખી મધ્યગા ત્રિકોણની અંદર હોય? શું વેધ હંમેશાં અંદર આવે?
  3. તમે એવો ત્રિકોણ વિચારી શકો જેના બે વેધ તેની બે બાજુ જ હોય?
  4. કોઈ ત્રિકોણ માટે વેધ અને મધ્યગા સમાન હોઈ શકે?
આકૃતિ 4–5 ઉપરથી વિચારો (સમબાજુ/સમદ્વિબાજુ પણ દોરો — "આ કરો"). જવાબ Answer Key માં.
સામાન્ય ભૂલ"વેધ = મધ્યગા" — ના. મધ્યગા મધ્યબિંદુ સુધી; વેધ લંબ (90°) સુધી. બંને સરખાં ક્યારેક જ.
જાતે ચકાસોમધ્યગા કોને કહે? વેધનો એક છેડો ક્યાં?
જવાબ: શિરોબિંદુ અને સામેની બાજુના મધ્યબિંદુને જોડતો રેખાખંડ; શિરોબિંદુ (બીજો છેડો સામેની બાજુને સમાવતી રેખા પર, લંબ)

02બહિષ્કોણ અને તેનો ગુણધર્મ

શા માટે ભણવું: બહારનો ખૂણો = અંદરના સામેના બે ખૂણાનો સરવાળો (પાન 89–91).

ΔABC ની બાજુ BC ને D સુધી લંબાવો. C આગળ બનતો ∠ACD = ત્રિકોણનો બહિષ્કોણ (ત્રિકોણની બહારના ભાગમાં). ∠BCA તેનો આસન્નકોણ. બાકીના બે ખૂણા ∠A અને ∠B = અંતઃસંમુખકોણ (દૂરના અંતઃકોણ).

આકૃતિ 6 — ઉદાહરણ 1 ના જ માપ: ∠A = 50°, ∠B = x = 60° ⇒ ∠C = 70°; બહિષ્કોણ ∠ACD = 180° − 70° = 110° = 50° + 60°.
બહિષ્કોણનો ગુણધર્મ
બહિષ્કોણ = બે અંતઃસંમુખકોણનો સરવાળો → ∠ACD = ∠A + ∠B
પ્રવૃત્તિ: ∠A અને ∠B કાપીને ∠ACD પર ગોઠવો — બરાબર ભરાય (પુસ્તક, પાન 89).

2a. સાબિતી (પાન 90)

આકૃતિ 7 — પક્ષ: ΔABC, ∠ACD બહિષ્કોણ. સાધ્ય: ∠ACD = ∠A + ∠B. રચના: C માંથી CE ∥ BA.
આકૃતિ 8 — સાબિતીનાં ચાર પગલાં અને દરેકનું કારણ (પુસ્તકનું કોષ્ટક).
ઉદાહરણ 1 (પાન 91)
આપ્યું: ΔABC માં ∠A = 50°, બહિષ્કોણ = 110°, ખૂણો x શોધવો (B આગળ).
રીત: અંતઃસંમુખકોણનો સરવાળો = બહિષ્કોણ.
ગણતરી: 50° + x = 110° ⇒ x = 110° − 50° = 60°
ચકાસો: 50° + 60° + 70° = 180° અને 50° + 60° = 110° ✓
આકૃતિ 9 — દરેક શિરોબિંદુ આગળ બે બહિષ્કોણ (બંને બાજુ લંબાવતાં) — કુલ 6; દરેક જોડ સરખી (સામસામેના ખૂણા). A, B, C આગળ 130°, 120°, 110° (180° − અંદરનો ખૂણો).
રોજિંદું ઉદાહરણત્રિકોણ આકારના બગીચાની ફરતે ચાલતાં દરેક ખૂણે તમારે જેટલું વળવું પડે તે બહિષ્કોણ જેવું — સીધી દિશા ચાલુ રાખવાને બદલે નવી દિશામાં વળવાનો ખૂણો (સમજ માટેની ઉપમા).
વિચારો, ચર્ચા કરો (પુસ્તક)
  1. બહિષ્કોણ કાટકોણ/ગુરુકોણ/લઘુકોણ હોય તો બંને અંતઃસંમુખકોણ વિશે શું કહી શકાય?
  2. શું ત્રિકોણનો બહિષ્કોણ સરળકોણ (180°) હોઈ શકે?
  3. ત્રિકોણના દરેક ખૂણા આગળ બનતા બહિષ્કોણ સરખા છે?
ઉપરના ગુણધર્મ + "બંને અંતઃસંમુખકોણ ધન" થી જાતે વિચારો. જવાબ Answer Key માં (સાથે "પ્રયત્ન કરો" 6.12 નો ખોટો ખૂણો).
સામાન્ય ભૂલ"બહિષ્કોણ = કોઈ પણ બે ખૂણાનો સરવાળો" — ના. ફક્ત તેના સામેના (દૂરના) બે અંતઃકોણનો. આસન્નકોણ (C પોતે) સાથે બહિષ્કોણ = 180° − ∠C.
જાતે ચકાસોΔABC માં ∠A = 40°, ∠B = 65° — C આગળનો બહિષ્કોણ? (તમારું નવું ઉદાહરણ)
જવાબ: 40° + 65° = 105°
→ આગળ: ખૂણાનો સરવાળો — Part 03.

03ત્રિકોણના ખૂણાના સરવાળાનો ગુણધર્મ

શા માટે ભણવું: ત્રણેય ખૂણા ભેગા = 180° — ચાર પ્રવૃત્તિ અને સાબિતી (પાન 92–94).

પ્રવૃત્તિ 1: ત્રિકોણ દોરો, ત્રણ ખૂણા કાપો, એક બિંદુએ ગોઠવો — તે સરળકોણ (સીધી રેખા) બનાવે = 180°.

આકૃતિ 10 — ત્રિકોણ (50°, 60°, 70°) ના ત્રણ ખૂણા એક બિંદુએ સીધી રેખા પર: 60° + 50° + 70° = 180° (અમારું ઉદાહરણ; કાપેલા ખૂણા).

પ્રવૃત્તિ 2: ત્રિકોણની ત્રણ નકલ — ખૂણા 1, 2, 3 બાજુ-બાજુ ગોઠવો. પ્રવૃત્તિ 3: ત્રિકોણ A આગળ વાળીને A થી આધાર પર લંબ AM બનાવો; ત્રણ ખૂણા A, B, C ને M પર અડાડો — ત્રણે મળી સરળકોણ. પ્રવૃત્તિ 4: ત્રણ ત્રિકોણ દોરી ખૂણા માપો, ત્રણ ખૂણાનો સરવાળો કોષ્ટકમાં — દરેકમાં 180° (કે નાની ભૂલથી લગભગ).

ખૂણાના સરવાળાનો ગુણધર્મ
ત્રિકોણના ત્રણે ખૂણાના માપનો સરવાળો = 180°
∠1 + ∠2 + ∠3 = 180° (પાન 94).

3a. સાબિતી (બહિષ્કોણના ગુણધર્મ પરથી)

આકૃતિ 11 — ΔABC, BC ને D સુધી લંબાવી ∠4 = બહિષ્કોણ. ∠1 + ∠2 = ∠4 (ગુણધર્મ); બંને બાજુ ∠3 ઉમેરતાં ∠1 + ∠2 + ∠3 = ∠4 + ∠3 = 180° (રૈખિક જોડ).
આકૃતિ 12 — સાબિતીનું કોષ્ટક (પાન 94).
ઉદાહરણ 2 (પાન 94)
આપ્યું: ΔPQR માં ∠Q = 47°, ∠R = 52°. m∠P શોધો.
રીત: ત્રિકોણના ખૂણાના સરવાળાનો ગુણધર્મ: m∠P + 47° + 52° = 180°.
ગણતરી: m∠P = 180° − 47° − 52° = 180° − 99° = 81°
ચકાસો: 81° + 47° + 52° = 180° ✓
રોજિંદું ઉદાહરણકાગળના ત્રિકોણના ખૂણા વાળીને ભેગા કરતાં સીધી ધાર — આ જ ગુણધર્મ. મોટા ત્રિકોણમાં પણ આ જ — ખેતરનો ત્રિકોણ ટુકડો, પતંગનો ત્રિકોણ.
વિચારો, ચર્ચા કરો (પુસ્તક)
  1. બે કાટખૂણાવાળો ત્રિકોણ મળે? બે ગુરુકોણવાળો? બે લઘુકોણવાળો?
  2. ત્રણેય ખૂણા 60° કરતાં મોટા / નાના / બરાબર 60° — કયો ત્રિકોણ મળે?
  3. ત્રિકોણના કોઈ બે ખૂણાનો સરવાળો ત્રીજા કરતાં હંમેશાં વધુ?
ગુણધર્મ 180° અને અસમતા પરથી જાતે વિચારો; જવાબ Answer Key માં.
સામાન્ય ભૂલ"ત્રણ ખૂણા ભેગા 360°" — ના. ચતુષ્કોણના ચાર ખૂણા 360° (પછી). ત્રિકોણના 180°.
જાતે ચકાસોત્રિકોણના બે ખૂણા 35° અને 75° (અમારું નવું ઉદાહરણ) — ત્રીજો?
જવાબ: 180° − 35° − 75° = 70°
→ આગળ: સમબાજુ-સમદ્વિબાજુ — Part 04.

04સમબાજુ અને સમદ્વિબાજુ ત્રિકોણ

શા માટે ભણવું: વિશેષ ત્રિકોણના ખૂણા (પાન 95–96).

સમબાજુ ત્રિકોણ: ત્રણેય બાજુ સમાન. બે નકલ કાપી એકબીજા પર મૂકો — કોઈ પણ દિશામાં બરાબર બંધબેસે. તેથી ત્રણેય ખૂણા પણ સમાન — 180° ÷ 3 = 60°.

સમદ્વિબાજુ ત્રિકોણ: બે બાજુ સમાન (XY = XZ). કાપી વાળો — Z એ Y પર આવે; XM = સંમિતિની અક્ષ (પ્રકરણ 12). XY, XZ = સમાન બાજુ; YZ = આધાર; ∠Y અને ∠Z = આધારના ખૂણા — સમાન.

આકૃતિ 13 — ડાબે સમબાજુ (ત્રણેય બાજુ સરખી, દરેક ખૂણો 60°). જમણે સમદ્વિબાજુ XY = XZ (બાજુઓ 5, 5, 4 — અમારું ઉદાહરણ): આધારના ખૂણા Y અને Z સરખા (≈ 66°); ટપકાંવાળી રેખા XM સંમિતિની અક્ષ.
યાદ રાખવું
સમબાજુ: દરેક ખૂણો 60° · સમદ્વિબાજુ: સમાન બાજુની સામેના ખૂણા સમાન
સમદ્વિબાજુમાં (i) બે બાજુ સરખી, (ii) સમાન બાજુની સામેના ખૂણા સમાન (પાન 96).
રોજિંદું ઉદાહરણત્રિકોણ આકારનો પતંગ કે ધજા — બે બાજુ સરખી, વચ્ચેથી વાળતાં બંને બાજુ સરખી (સંમિતિ). સમબાજુ ત્રિકોણ = ત્રણેય બાજુની પટ્ટીઓ સરખી — રોડ-સાઇન "સાવધાન" નું બોર્ડ.
સામાન્ય ભૂલ"સમદ્વિબાજુમાં ત્રીજો ખૂણો પણ સરખો" — ના. ફક્ત આધારના બે ખૂણા સરખા; ત્રીજો (શિરોબિંદુનો) જુદો (સમબાજુ સિવાય).
જાતે ચકાસોસમબાજુ ત્રિકોણનો દરેક ખૂણો? સમદ્વિબાજુમાં XY = XZ તો કયા ખૂણા સરખા?
જવાબ: 60°; ∠Y = ∠Z
→ આગળ: બાજુની લંબાઈનો ગુણધર્મ — Part 05.

05ત્રિકોણની બે બાજુની લંબાઈનો સરવાળો

શા માટે ભણવું: ત્રણ લંબાઈથી ત્રિકોણ બને કે નહિ? (પાન 97–99).

મેદાનમાં A, B, C ત્રણ (સમરેખ નહિ) બિંદુ. A થી C પહોંચવા સીધો AC કે AB થી થઈ BC — સ્વાભાવિક રીતે સીધો ટૂંકો: AB + BC > AC. એ જ રીતે BC + CA > AB, CA + AB > BC.

આકૃતિ 14 — A → C સીધો (લીલો, 5 સેમી) અને B થઈને (લાલ, 6 + 7 = 13 સેમી). અમારાં માપ 6, 7, 5.
આકૃતિ 15 — ત્રણેય રસ્તાની અસમતા (પાન 97).
ગુણધર્મ
કોઈ પણ બે બાજુનો સરવાળો > ત્રીજી બાજુ · કોઈ પણ બે બાજુનો તફાવત < ત્રીજી બાજુ
લાકડીઓની પ્રવૃત્તિ: 6, 12 ની બે લાકડી — ત્રીજી 18 સેમીથી ઓછી જોઈએ (પાન 97).
ઉદાહરણ 3 (પાન 99)
આપ્યું: બાજુઓ 10.2 સેમી, 5.8 સેમી, 4.5 સેમી — ત્રિકોણ શક્ય?
રીત: કોઈ પણ બે બાજુનો સરવાળો ત્રીજી કરતાં વધુ હોવો જોઈએ — ત્રણેય ચકાસો.
ગણતરી: 4.5 + 5.8 = 10.3 > 10.2 ✓ · 5.8 + 10.2 = 16 > 4.5 ✓ · 10.2 + 4.5 = 14.7 > 5.8 ✓
જવાબ: ત્રણેય સાચાં ⇒ આવો ત્રિકોણ શક્ય છે.
આકૃતિ 16 — ઉદાહરણ 3: બે ટૂંકી (5.8 + 4.5 = 10.3) લાંબી (10.2) કરતાં બહુ થોડી — 0.1 — વધુ, છતાં ત્રિકોણ બને.
ઉદાહરણ 4 (પાન 99)
આપ્યું: બે બાજુ 6 સેમી અને 8 સેમી. ત્રીજી બાજુ કઈ બે સંખ્યા વચ્ચે?
રીત: ત્રીજી < સરવાળો; ત્રીજી > તફાવત.
ગણતરી: ઉપરની હદ: 8 + 6 = 14; નીચેની હદ: 8 − 6 = 2
જવાબ: ત્રીજી બાજુ 2 સેમીથી મોટી અને 14 સેમીથી નાની કોઈ પણ લંબાઈની.
આકૃતિ 17 — ઉદાહરણ 4: 2 અને 14 વચ્ચેની બધી લંબાઈ ચાલે; ખુલ્લાં ટપકાં = 2 અને 14 પોતે નહિ.
રોજિંદું ઉદાહરણત્રણ સોટીથી ત્રિકોણ બનાવો: 2, 3, 6 સેમી — ગમે તેટલું પ્રયત્ન કરો ન બને (2 + 3 = 5 < 6). 3, 4, 5 બને.
વિચારો (પુસ્તક)શું ત્રિકોણના કોઈ પણ બે ખૂણાનો સરવાળો હંમેશાં ત્રીજા ખૂણા કરતાં વધુ હોય છે? ખૂણા માટે કયો ગુણધર્મ વાપરશો? જવાબ Answer Key માં.
સામાન્ય ભૂલ"ફક્ત એક જોડનો સરવાળો જોઈ લેવો" — ત્રણેય જોડ ચકાસો; પણ સૌથી લાંબી બાજુ સામે બાકીની બેનો સરવાળો જોઈ લો તો ત્રણેય સાચાં (ટૂંકો રસ્તો).
જાતે ચકાસો2 સેમી, 3 સેમી, 5 સેમી ત્રિકોણ બને? (તમારો ઉદાહરણ)
જવાબ: ના — 2 + 3 = 5, 5 કરતાં વધુ નથી

06કાટકોણ ત્રિકોણ અને પાયથાગોરસનો ગુણધર્મ

શા માટે ભણવું: પરીક્ષાનો સૌથી મોટો ગુણધર્મ: કર્ણ² = પાયા² નો સરવાળો (પાન 100–103).

કાટકોણ ત્રિકોણમાં કાટખૂણાની સામેની બાજુ = કર્ણ (hypotenuse); બાકીની બે = પાયા. ΔABC માં B આગળ કાટખૂણો ⇒ AC કર્ણ; AB, BC પાયા. કર્ણ સૌથી લાંબી બાજુ. (પુસ્તક: છઠ્ઠી સદી ઈ.સ. પૂર્વે ગ્રીક તત્ત્વજ્ઞાની પાયથાગોરસ; બૌધાયન પણ સમકક્ષ ગુણધર્મ દર્શાવ્યો.)

6a. સાબિતી ક્ષેત્રફળ વડે (આકૃતિ 6.25)

કર્ણ a, પાયા b અને c. b + c બાજુના બે સરખા ચોરસ દોરો. ચોરસ A માં ચાર કાટકોણ ત્રિકોણ ગોઠવો — વચ્ચે a² નો ચોરસ. ચોરસ B માં ચાર એવા જ ત્રિકોણ — બાકી b² અને c² ના બે ચોરસ. ચોરસ સરખા, ત્રિકોણ સરખા ⇒ બાકીનાં ક્ષેત્રફળ સરખાં: a² = b² + c².

આકૃતિ 18 — 3-4-5 લઈને: બંને ચોરસની બાજુ 7 ⇒ 49. દરેકમાં ચાર ત્રિકોણ = 4 × (3 × 4 ÷ 2) = 24. ચોરસ A: 24 + 25 = 49; ચોરસ B: 24 + 16 + 9 = 49 ⇒ 25 = 16 + 9.
પાયથાગોરસનો ગુણધર્મ
કાટકોણ ત્રિકોણમાં: કર્ણ² = પાયા₁² + પાયા₂² → a² = b² + c²
કર્ણ પરના ચોરસનું ક્ષેત્રફળ = બાકીની બે બાજુ પરના ચોરસના ક્ષેત્રફળનો સરવાળો (પાન 101).
આકૃતિ 19 — આકૃતિ 6.26 જેવું: 3-4-5 ત્રિકોણની ત્રણેય બાજુ પર ચોરસ. ખાનાં ગણો: 9 + 16 = 25.
આકૃતિ 20 — વિચારનો ક્રમ.

6b. ઊલટું: ત્રિકોણ કાટકોણ છે?

જો ત્રિકોણ માટે બે બાજુના વર્ગનો સરવાળો ત્રીજી બાજુના વર્ગ જેટલો થાય તો તે ત્રિકોણ કાટકોણ જ હોય. પ્રવૃત્તિ: 4, 5, 6 સેમી ચોરસ ગોઠવી ત્રિકોણ મેળવો — 4² + 5² ≠ 6² ⇒ દરેક ખૂણો લઘુકોણ. 4, 5, 7 સેમી — 4² + 5² ≠ 7² ⇒ એક ગુરુકોણ.

આકૃતિ 21 — પરિણામ અને ઊલટું (પાન 101–102).
આકૃતિ 22 — ચાર ત્રિપુટી: a² + b² = c² તો સૌથી મોટો ખૂણો 90°. 4, 5, 6: 82.8° (બધા લઘુકોણ); 4, 5, 7: 101.5° (ગુરુકોણ). ખૂણા કોસાઇન-નિયમથી ગણ્યા — વધારાનું, પરીક્ષા માટે જરૂરી નથી.
ઉદાહરણ 5 (પાન 102)
આપ્યું: બાજુઓ 3 સેમી, 4 સેમી, 5 સેમી — કાટકોણ ત્રિકોણ?
રીત: સૌથી લાંબી 5 ને કર્ણ ધારી ચકાસો.
ગણતરી: 3² = 9; 4² = 16; 5² = 25; 3² + 4² = 9 + 16 = 25 = 5²
જવાબ: હા, કાટકોણ ત્રિકોણ (કર્ણ 5 સેમી).
ઉદાહરણ 6 (પાન 102)
આપ્યું: ΔABC માં ∠C = 90°, AC = 5 સેમી, BC = 12 સેમી. AB = ?
રીત: પાયથાગોરસ: AB² = AC² + BC².
ગણતરી: AB² = 5² + 12² = 25 + 144 = 169 = 13²
જવાબ: AB = 13 સેમી (કર્ણ).
આકૃતિ 23 — ઉદાહરણ 6 ચિત્ર: 5-12-13 ત્રિકોણ; ચોરસ 25, 144, 169 — 25 + 144 = 169.
રોજિંદું ઉદાહરણનિસરણી દીવાલ ટેકવતાં દીવાલ, જમીન અને નિસરણીથી કાટકોણ ત્રિકોણ — કર્ણ = નિસરણી. 5 મીટરની નિસરણીનો છેડો દીવાલથી 3 મીટર દૂર → દીવાલ પર 4 મીટર ઊંચે (3-4-5; અમારું ઉદાહરણ). મિસ્ત્રી 3-4-5 ની દોરીથી ખૂણો કાટખૂણો ચકાસે (વધારાની વાત).
વિચારો (પુસ્તક)P આગળ કાટખૂણો હોય તેવા ΔPQR ની લાંબામાં લાંબી બાજુ કઈ? B આગળ કાટખૂણાવાળા ΔABC ની? કાટકોણ ત્રિકોણની લાંબામાં લાંબી બાજુ કઈ? કર્ણની વ્યાખ્યા પરથી વિચારો; જવાબ Answer Key માં. બૌધાયનના પ્રમેય સાથે સરખામણી — પુસ્તકનો પ્રશ્ન 4.
સામાન્ય ભૂલ"કર્ણ = કોઈ પણ બાજુ" — ના. કર્ણ = કાટખૂણાની સામેની બાજુ, સૌથી લાંબી. a² = b² + c² માં a કર્ણ જ.
જાતે ચકાસો3 સેમી, 4 સેમી પાયાવાળા કાટકોણ ત્રિકોણનો કર્ણ? (પાયા 5, 12 નહિ — નવું ઉદાહરણ)
જવાબ: √(9 + 16) = √25 = 5 સેમી

07સારાંશ અને પરીક્ષાના નમૂના

શા માટે ભણવું: પાન 104–105 "આપણે શું ચર્ચા કરી?" — 11 મુદ્દા.

યાદ રાખો
  1. ત્રિકોણના છ અંગો: 3 બાજુ, 3 ખૂણા. મધ્યગા = શિરોબિંદુ → સામેની બાજુનું મધ્યબિંદુ (ત્રણ); વેધ = શિરોબિંદુ → સામેની બાજુ પર લંબ (ત્રણ).
  2. બહિષ્કોણ = બે અંતઃસંમુખકોણનો સરવાળો; દરેક શિરોબિંદુ આગળ બે બહિષ્કોણ.
  3. ત્રિકોણના ત્રણ ખૂણાનો સરવાળો 180°.
  4. સમબાજુ: ત્રણેય બાજુ સરખી, ખૂણા 60°. સમદ્વિબાજુ: બે બાજુ સરખી, આધારના ખૂણા સરખા.
  5. કોઈ બે બાજુનો સરવાળો > ત્રીજી; તફાવત < ત્રીજી.
  6. કાટકોણ: કર્ણ² = બાકીની બેના વર્ગનો સરવાળો; ઊલટું: સરવાળો સમાન મળે તો ત્રિકોણ કાટકોણ.

પરીક્ષાના નમૂના જવાબ (પુસ્તકના ઉદાહરણો પ્રમાણે)

નોંધઆ ગુણ પ્રમાણે જવાબ કેવો લખવો તેના થોડા નમૂના છે. સ્વાધ્યાય 6.1–6.5, "પ્રયત્ન કરો" અને સ્વાધ્યાયપોથી/પ્રેક્ટિસ બુકના બધા ઉકેલ જવાબ-પત્રકમાં આવશે — બંને પુસ્તકો મળ્યા પછી. Maths નો પ્રથમ સત્રાંતનો અભ્યાસક્રમ/પેપર પદ્ધતિ હજી મળ્યાં નથી.
નમૂનો 1 — વ્યાખ્યા
પ્ર. મધ્યગા અને વેધ સમજાવો.
જ. મધ્યગા: ત્રિકોણના શિરોબિંદુને તેની સામેની બાજુના મધ્યબિંદુ સાથે જોડતો રેખાખંડ. વેધ: ત્રિકોણના શિરોબિંદુમાંથી સામેની બાજુને સમાવતી રેખા પર દોરેલો લંબ રેખાખંડ. દરેકની સંખ્યા ત્રણ.
નમૂનો 2 — ગણતરી
પ્ર. ΔPQR માં ∠Q = 47°, ∠R = 52° તો m∠P શોધો.
જ. આપ્યું: ∠Q = 47°, ∠R = 52°. ગુણધર્મ: ખૂણાનો સરવાળો 180°. m∠P = 180° − 47° − 52° = 81°.
નમૂનો 3 — પાયથાગોરસ
પ્ર. કાટકોણ ΔABC માં ∠C = 90°, AC = 5, BC = 12 હોય તો AB?
જ. AB² = AC² + BC² = 25 + 144 = 169 ⇒ AB = 13 સેમી.
નમૂનો 4 — ગુણધર્મ લખો
પ્ર. બહિષ્કોણનો ગુણધર્મ લખો.
જ. ત્રિકોણના કોઈ પણ બહિષ્કોણનું માપ તેના અંતઃસંમુખ ખૂણાના માપના સરવાળા જેટલું હોય છે.

08વાલી માટે

વાલી માટે
  • કાગળના ત્રિકોણથી ત્રણ ખૂણા ફાડી સીધી રેખા પર ગોઠવવા કહો (આકૃતિ 10) — 180° જાતે જોવા દો.
  • ત્રણ સોટી (2, 3, 6 સેમી અને 3, 4, 5 સેમી)થી ત્રિકોણ બનાવો — કઈ બને, કઈ નહિ (આકૃતિ 16–17).
  • ઘરમાં 3-4-5 ની દોરીથી દીવાલ-ફર્શનો ખૂણો કાટખૂણો છે તે ચકાસો (વધારાની વાત).
  • સામાન્ય ભૂલ: કર્ણ ખોટી બાજુને ગણવી; બહિષ્કોણમાં આસન્ન ખૂણો ઉમેરવો; મધ્યગા-વેધ ગૂંચવવા; બે-બે બાજુના સરવાળાની ફક્ત એક જ જોડ ચકાસવી.
  • ચિત્ર-પસંદગી (chart audit): ખૂણા અને બાજુ માપ મુજબ ગણીને દોર્યા; ચોરસના ક્ષેત્રફળ ગણીને; સાબિતી = ફ્લો + કોષ્ટક.
