00પ્રકરણ એક નજરે

શા માટે ભણવું: −3/4 કિમી (સમુદ્રની નીચે) જેવી વાતો — ઋણ અને અપૂર્ણાંક બંને એક સાથે — પૂર્ણાંકથી ન લખાય. તે માટે સંખ્યા-પદ્ધતિ વિસ્તારી: સંમેય સંખ્યાઓ.

આ પ્રકરણ પછી તમે (1) સંમેય સંખ્યા ઓળખી શકશો, (2) સમાન સંમેય અને પ્રમાણિત રૂપ લખી શકશો, (3) સંખ્યારેખા પર દર્શાવી, સરખાવી અને બે વચ્ચેની સંખ્યાઓ લખી શકશો, (4) સરવાળો-બાદબાકી-ગુણાકાર-ભાગાકાર કરી શકશો.
શબ્દોનો પાયોસંમેય (rational) શબ્દ ગુણોત્તર (ratio) પરથી — p અને q નો ગુણોત્તર p : q = p/q (પાન 123). અંશ = ઉપરનો ભાગ (p); છેદ = નીચેનો ભાગ (q ≠ 0). સમાન = સરખી કિંમતવાળી. પ્રમાણિત = પ્રમાણ (ધોરણ) મુજબનું રૂપ. વિરોધી ઘટક = સામેનું (સરવાળે 0). વ્યસ્ત = ઊલટું (ગુણાકારે 1). લ.સા.અ. = લઘુત્તમ સામાન્ય અવયવ (LCM) — છેદ સમાન કરવા; ગુ.સા.અ. = ગુરુત્તમ સામાન્ય અવયવ (HCF) — સંક્ષિપ્ત રૂપ માટે.
આકૃતિ 1 — સંખ્યા-પદ્ધતિ મોટી થતી ગઈ: પ્રાકૃતિક (1, 2, 3…) → પૂર્ણ (0 સાથે) → પૂર્ણાંક (ઋણ સાથે) → સંમેય (અપૂર્ણાંક સાથે). દરેક નાની સંખ્યા મોટા સમૂહમાં સમાય (પાન 121, 140).
આકૃતિ 2 — આખા પ્રકરણનું સારાંશ-ચિત્ર: હરોળ = ખ્યાલ; સ્તંભ = શું / યાદ રાખવાની વાત.
રોજિંદું ઉદાહરણ"સમુદ્રસપાટીથી 3/4 કિમી નીચે" = −3/4. ₹150 નો નફો +150 અને ₹100 ની ખોટ −100 (પાન 122) — એ જ રીતે −3/4. ઊંડા કૂવાનું પાણીનું સ્તર, તાપમાન −2.5°C — ઋણ અપૂર્ણાંક.
સામાન્ય ભૂલ"અપૂર્ણાંક સંમેય નથી" — ખોટું. બધા પૂર્ણાંક અને બધા અપૂર્ણાંક સંમેય સંખ્યાઓ છે (પાન 123).

01સંમેય સંખ્યા અને સમાન સંમેય

શા માટે ભણવું: p/q સ્વરૂપ અને એક જ સંખ્યાનાં અનેક રૂપ (પાન 122–124).

સંમેય સંખ્યાની વ્યાખ્યા
p/q, જ્યાં p અને q પૂર્ણાંક છે અને q ≠ 0
4/5: p = 4, q = 5. −3/4 પણ સંમેય (p = −3, q = 4). 0.5 = 5/10, 0.333 = 333/1000. પૂર્ણાંક −5 = −5/1, 0 = 0/2.

પુસ્તકના પ્રશ્ન: શું 2/−3 સંમેય છે? હા — p = 2 અને q = −3 બંને પૂર્ણાંક છે અને q ≠ 0. (છેદ ઋણ હોઈ શકે; છેદ 0 ન હોઈ શકે.)

આકૃતિ 3 — −2/3 = −2×2 / 3×2 = −4/6; −2×(−5) / 3×(−5) = 10/−15. અંશ-છેદને સરખા શૂન્યેતર પૂર્ણાંકથી ગુણતાં કે ભાગતાં સમાન સંમેય સંખ્યા મળે; બધાં રૂપ સંખ્યારેખા પર એક જ બિંદુ. (પુસ્તકના 10/−15 = −10/15 પણ.)
પુસ્તકની ગણતરી (પાન 124)
ગુણાકારથી: −2/3 = (−2 × 2)/(3 × 2) = −4/6 ; (−2 × −5)/(3 × −5) = 10/−15
ભાગાકારથી: 10/−15 = (10 ÷ −5)/(−15 ÷ −5) = −2/3 ; −12/24 = −12÷12 / 24÷12 = −1/2
અર્થ: −2/3 = −4/6 = 10/−15; અને 10/−15 = −10/15
રોજિંદું ઉદાહરણ1/2 લિટર દૂધ = 2/4 લિટર = 5/10 લિટર — કિંમત એ જ, લખવાની રીત જુદી. ઋણમાં પણ: −1/2 = −3/6.
પ્રયત્ન કરો (પુસ્તક)શું 2/−3 સંમેય છે? દસ સંમેય સંખ્યાઓની યાદી બનાવો. ખાલી જગ્યા: 5/4 = □/16 = 25/□ = −15/□; −3/7 = □/14 = 9/□ = −6/□ — જવાબ Answer Key માં.
સામાન્ય ભૂલ"છેદ 0 હોઈ શકે" — ના. p/0 સંમેય નથી. અને અંશ-છેદ બંનેને સરખી (શૂન્યેતર) સંખ્યાથી જ ગુણવા-ભાગવા.
જાતે ચકાસો3/7 નું એક સમાન રૂપ? (પુસ્તકનું ઉદાહરણ: −3/7 = −6/14)
જવાબ: 3/7 = 6/14 = 9/21; −3/7 = −6/14
→ આગળ: ધન, ઋણ — Part 02.

02ધન, ઋણ સંમેય અને સંખ્યારેખા

શા માટે ભણવું: અંશ-છેદનાં ચિહ્ન અને સંખ્યારેખા પરનું સ્થાન (પાન 124–126).

જેમાં અંશ અને છેદ બંને ધન પૂર્ણાંક તે ધન સંમેય (3/8, 5/7, 2/9). અંશ ઋણ અને છેદ ધન તે ઋણ સંમેય (−3/5, −5/7). 8/−3 = −8/3 ઋણ છે; −3/−5 = 3/5 ધન છે. 0 ન ધન, ન ઋણ.

આકૃતિ 4 — પાંચ નમૂના: 3/8 (ધન), −3/5 (ઋણ), 8/−3 (ઋણ), −3/−5 (ધન), 0 (ન ધન ન ઋણ).
આકૃતિ 5 — ચિહ્નનું નિર્ણય-વૃક્ષ (પાન 124–125, 140).

2a. સંખ્યારેખા પર −1/2, −3/2

0 ની જમણી બાજુ ધન, ડાબી બાજુ ઋણ. 1/2 અને −1/2 બંને 0 થી સમાન અંતરે. −1/2 = 0 અને −1 ની વચ્ચે અડધા અંતરે. −3/2 = −1 અને −2 ની વચ્ચે અડધા અંતરે; −5/2, −7/2 એ જ રીતે; −1/3 = 0 અને −1 વચ્ચે ત્રીજા ભાગે (પાન 125–126).

આકૃતિ 6 — સંખ્યારેખા −1 થી 0: −1/2 = −5/10 અને −1/5 = −2/10 ના બિંદુ (પાન 128 — મેરીની રીત). જમણી બાજુની સંખ્યા મોટી.
રોજિંદું ઉદાહરણથર્મોમીટર: −1/2°C (શૂન્યથી થોડું નીચે) અને −1/5°C — −1/5°C ઓછું ઠંડું (વધુ ગરમ) એટલે મોટું.
પ્રયત્ન કરો (પુસ્તક)શું −8 ઋણ સંમેય છે? 5 ઋણ સંમેય? ઋણ-સંમેય સંખ્યાઓની યાદી; 0 ની કઈ બાજુ −1/2? સંખ્યારેખા પરથી જાતે; જવાબ Answer Key માં. (−8 = −8/1 ઋણ સંમેય — પુસ્તક: પૂર્ણાંકો પણ સંમેય.)
સામાન્ય ભૂલ"−3/−5 ઋણ" — ના. બંને ચિહ્ન ઋણ ⇒ −3/−5 = 3/5 ધન (પાન 125).
જાતે ચકાસો−7/9 ધન કે ઋણ? 4/−3? (નવા ઉદાહરણ)
જવાબ: ઋણ; ઋણ (= −4/3)
→ આગળ: પ્રમાણિત સ્વરૂપ — Part 03.

03પ્રમાણિત સ્વરૂપ

શા માટે ભણવું: સૌથી સંક્ષિપ્ત રૂપ — છેદ ધન અને સામાન્ય અવયવ ફક્ત 1 (પાન 126–127).

સંમેય સંખ્યા પ્રમાણિત સ્વરૂપમાં ત્યારે કહેવાય જ્યારે (i) છેદ ધન પૂર્ણાંક હોય, (ii) અંશ અને છેદમાં 1 સિવાય બીજો સામાન્ય અવયવ ન હોય. ઉદાહરણ: 3/5, −5/8, 2/7, −7/11.

આકૃતિ 7 — ઉદાહરણ 1: −45/30 ÷ 15 ⇒ −3/2. ઉદાહરણ 2(i): 36/−24 ને ગુ.સા.અ. 12 ના ઋણ (−12) વડે ભાગતાં −3/2; (ii) −3/−15 ÷ (−3) = 1/5.
ઉદાહરણ 1 (પાન 127)
આપ્યું: −45/30 ને પ્રમાણિત સ્વરૂપમાં.
રીત: ગુ.સા.અ. (45, 30) = 15; અંશ-છેદને 15 વડે ભાગો.
ગણતરી: −45/30 = (−45 ÷ 15)/(30 ÷ 15) = −3/2
ચકાસો: −3 અને 2 નો સામાન્ય અવયવ ફક્ત 1; છેદ ધન ✓
ઉદાહરણ 2 (પાન 127)
આપ્યું: (i) 36/−24 (ii) −3/−15 ને પ્રમાણિત રૂપમાં.
રીત: છેદ ઋણ હોય ⇒ "−ગુ.સા.અ." વડે ભાગો.
(i): ગુ.સા.અ. (36, 24) = 12 ⇒ 36/−24 = (36 ÷ −12)/(−24 ÷ −12) = −3/2
(ii): ગુ.સા.અ. (3, 15) = 3 ⇒ −3/−15 = (−3 ÷ −3)/(−15 ÷ −3) = 1/5
રોજિંદું ઉદાહરણઅપૂર્ણાંકને "અતિ સંક્ષિપ્ત" રૂપે લખવું = 12/18 ને 2/3 — એ જ રીત, ફક્ત ઋણ ચિહ્ન ધ્યાનમાં. રસોઈમાં 8/12 કપ = 2/3 કપ.
સામાન્ય ભૂલ"36/−24 ≠ −3/2" — બરાબર એ જ છે. છેદ ઋણ હોય તો પ્રમાણિત રૂપમાં છેદ ધન બનાવો: −12 વડે ભાગતાં છેદ +2.
જાતે ચકાસો−18/45 અને −12/18 નું પ્રમાણિત રૂપ? (પુસ્તકનો "પ્રયત્ન કરો")
જવાબ: −18/45 = −2/5 (÷9); −12/18 = −2/3 (÷6)
→ આગળ: સરખામણી — Part 04.

04સરખામણી અને બે વચ્ચેની સંમેય સંખ્યાઓ

શા માટે ભણવું: કોણ મોટું? અને બે સંખ્યા વચ્ચે કેટલી? (પાન 128–131).

ધન સંમેય: અપૂર્ણાંકની જેમ સરખાવો (સમાન છેદ). ઋણ સંમેય: ચિહ્ન છોડીને સરખાવો, પછી ક્રમ ઊલટાવો. ઋણ vs ધન: ઋણ હંમેશાં ધનથી નાની (સંખ્યારેખા પર 0 ની ડાબે).

આકૃતિ 8 — −7/5 અને −5/3: પહેલાં 7/5 = 21/15 < 5/3 = 25/15; ઋણ ચિહ્ન લગાવતાં ક્રમ ઊલટો ⇒ −7/5 > −5/3 (પાન 129).
ઉદાહરણ 3 (પાન 129)
આપ્યું: શું 4/−9 અને −16/36 સરખી સંમેય સંખ્યા છે?
રીત: બંનેને પ્રમાણિત રૂપમાં લાવો.
ગણતરી: 4/−9 = 4×(−4)/(−9)×(−4) = −16/36 ; અને −16/36 = (−16÷−4)/(36÷−4) = 4/−9
જવાબ: હા, સરખી.

4a. બે સંખ્યાની વચ્ચેની સંખ્યાઓ

બે ક્રમિક પૂર્ણાંકો વચ્ચે એક પણ પૂર્ણાંક નથી — પણ બે સંમેય વચ્ચે અનંત સંમેય. ઉદાહરણ: −3/5 અને −1/3 ને સમાન છેદ 15 કરો: −9/15 < −8/15 < −7/15 < −6/15 < −5/15 — ત્રણ સંખ્યા −8/15, −7/15, −6/15. વધુ છેદ લો (30): −17/30 પણ વચ્ચે (−3/5 < −17/30 < −8/15).

આકૃતિ 9 — −3/5 થી −1/3 વચ્ચે −8/15, −7/15, −6/15 (લીલાં ટપકાં). પુસ્તક: છેદ 150 લેતાં −89/150 થી −51/150 — 39 સંખ્યા.
આકૃતિ 10 — એ જ બે સંખ્યા વચ્ચે છેદ 15: 3 સંખ્યા; 30: 7; 150: 39 (−90/150 થી −50/150). યાદી કદી પૂરી ન થાય.
ઉદાહરણ 4 (પાન 131)
આપ્યું: −2 અને −1 ની વચ્ચે ત્રણ સંમેય સંખ્યાઓ.
રીત: છેદ 5: −1 = −5/5 અને −2 = −10/5.
ગણતરી: −10/5 < −9/5 < −8/5 < −7/5 < −6/5 < −5/5
જવાબ: −9/5, −8/5, −7/5 (કોઈ પણ ત્રણ).
ઉદાહરણ 5 (પાન 131) — પેટર્ન
આપ્યું: −1/3, −2/6, −3/9, −4/12, … પછીની ચાર સંખ્યા.
રીત: અંશ-છેદ ક્રમશ −1×k / 3×k.
ગણતરી: k = 5, 6, 7 : −5/15, −6/18, −7/21 (અને k = 8: −8/24)
અવલોકન: બધી −1/3 ની સમાન સંમેય સંખ્યાઓ.
રોજિંદું ઉદાહરણ1 અને 2 ની વચ્ચે કેટલા અપૂર્ણાંક? 1.1, 1.25, 1.5, 1.99 … ગણી ન શકાય. એ જ ઋણમાં.
પ્રયત્ન કરો અને વિચારો (પુસ્તક)−3/8 કે −2/7 — કઈ મોટી? −4/3 કે −3/2? −5/7 અને −3/8 વચ્ચેની પાંચ સંખ્યા; −5/3 અને −8/7 વચ્ચેની પાંચ. ઉપરની રીતે જાતે; જવાબ Answer Key માં.
સામાન્ય ભૂલ"−1/2 > −1/5 કેમ કે 1/2 > 1/5" — ઋણ ચિહ્ન લગાવતાં ક્રમ ઊલટાય: −1/2 < −1/5 (પાન 128).
જાતે ચકાસો−2/7 અને 1/2 માં મોટી? (પુસ્તક: ઋણ હંમેશાં ધનથી નાની) −3/4 અને −2/3?
જવાબ: 1/2 (−2/7 < 1/2); −2/3 = −8/12 > −3/4 = −9/12

05સંમેય સંખ્યાઓ પર ક્રિયાઓ

શા માટે ભણવું: સરવાળો, બાદબાકી, ગુણાકાર, ભાગાકાર (પાન 133–139).

5a. સરવાળો

સમાન છેદ: છેદ કાયમ રાખી અંશનો સરવાળો. 7/3 + (−5/3): સંખ્યારેખા પર 7/3 થી 5 કૂદકા ડાબે ⇒ 2/3 = (7 + −5)/3. જુદા છેદ: લ.સા.અ. લઈ બંનેને સમાન છેદ કરો. −7/5 + (−2/3): લ.સા.અ. 15 ⇒ −21/15 + (−10/15) = −31/15.

આકૃતિ 11 — પાન 133: 7/3 + (−5/3) = 2/3 (ઋણ ઉમેરતાં ડાબે જવું).
આકૃતિ 12 — પાન 134: −7/8 + 5/8 = (−7 + 5)/8 = −2/8 = −1/4.
આકૃતિ 13 — સરવાળાના પગલાં: સમાન છેદ → અંશ; જુદા છેદ → લ.સા.અ.

5b. વિરોધી ઘટક

−4/7 + 4/7 = 0 અને 4/7 + (−4/7) = 0 ⇒ 4/7 નો વિરોધી ઘટક −4/7 અને −4/7 નો 4/7. એ જ રીતે −2/3 + 2/3 = 0.

ઉદાહરણ 6 (પાન 135)
આપ્યું: સતપાલ P થી પૂર્વમાં 2/3 કિમી ચાલ્યો, પછી પશ્ચિમમાં 1 5/7 કિમી. હવે P થી સ્થાન?
રીત: પૂર્વ = ધન; પશ્ચિમ = ઋણ.
ગણતરી: 2/3 + (−12/7) = 14/21 + (−36/21) = −22/21 = −1 1/21
જવાબ: મૂલ્ય ઋણ ⇒ P થી પશ્ચિમમાં 1 1/21 કિમી.

5c. બાદબાકી

આકૃતિ 14 — જેની બાદબાકી કરવાની હોય તેનો વિરોધી ઘટક પહેલી સંખ્યામાં ઉમેરો.

પુસ્તક: 5/7 − 3/8 = (40 − 21)/56 = 19/56 અને 5/7 + (−3/8) = 19/56 — સરખા. 1 2/3 − 2 4/5 = 5/3 − 14/5 = 5/3 + (−14/5) = −17/15 = −1 2/15. 2/7 − (−5/6) = 2/7 + 5/6 = 47/42 = 1 5/42.

5d. ગુણાકાર

આકૃતિ 15 — −3/5 × 2: 0 થી ડાબે 3/5 ના 2 કૂદકા ⇒ −6/5 = (−3 × 2)/5.
આકૃતિ 16 — બે સંમેયનો ગુણાકાર (પાન 137): −3/5 × 2/7 = −6/35; −5/8 × −9/7 = 45/56. ઋણ પૂર્ણાંક સાથે: −2/9 × (−5) = 10/9.

5e. ભાગાકાર

આકૃતિ 17 — વિરોધી ઘટક અને વ્યસ્ત: −2/7 નો વ્યસ્ત −7/2 (= 7/−2); સંખ્યા × તેનો વ્યસ્ત = 1 (−4/9 × −9/4 = 1).
આકૃતિ 18 — 4/9 ÷ (−5/7) = 4/9 × 7/−5 = −28/45. 6/−5 ÷ −2/3 = 6/−5 × 3/−2 = 9/5.
આકૃતિ 19 — ચારેય ક્રિયાઓ સારાંશમાં.
રોજિંદું ઉદાહરણદોરી: 1/2 મીટરના 3 ટુકડા = 3/2 મી. ઋણમાં: દર કલાકે −1/2°C તાપમાન — 4 કલાકે −2°C (−1/2 × 4).
પ્રયત્ન કરો (પુસ્તક)−13/7 + 6/7; 19/5 + (−7/5); −3/7 + 2/3; 7/9 − 2/5; −3/5 × 7; −3/4 × 1/7; 2/3 × −5/9 … ઉપરની રીતથી જાતે; બધા ઉકેલ Answer Key માં (સ્વાધ્યાય 8.2 સાથે).
સામાન્ય ભૂલ"−2/3 × −5 = −10/3" — બે ઋણનો ગુણાકાર ધન: (−2 × −5)/9 = 10/9 (પાન 137). અને ભાગાકારમાં બીજી સંખ્યાનો વ્યસ્ત, પહેલીનો નહિ.
જાતે ચકાસો−2/3 + 3/8 = ? (પાન 140) 7/8 − 2/3 = ?
જવાબ: −16/24 + 9/24 = −7/24; 7/8 + (−2/3) = 21/24 − 16/24 = 5/24
→ આગળ: સારાંશ — Part 06.

06સારાંશ અને પરીક્ષાના નમૂના

શા માટે ભણવું: પાન 140 "આપણે શું ચર્ચા કરી?" — એક પાનું.

યાદ રાખો
  1. સંમેય = p/q (q ≠ 0). બધા પૂર્ણાંક અને અપૂર્ણાંક સંમેય. સમાન સંમેય: સરખા શૂન્યેતર પૂર્ણાંકથી ગુણો/ભાગો.
  2. ધન: અંશ-છેદ સરખાં ચિહ્ન; ઋણ: જુદાં; 0 ન ધન ન ઋણ.
  3. પ્રમાણિત: છેદ ધન, સામાન્ય અવયવ 1.
  4. બે સંમેય વચ્ચે અનંત સંમેય.
  5. સરવાળો: સમાન છેદ → અંશ; જુદા છેદ → લ.સા.અ. બાદબાકી = વિરોધી ઘટક ઉમેરવો. ગુણાકાર = અંશ×અંશ/છેદ×છેદ. ભાગાકાર = વ્યસ્ત સાથે ગુણાકાર.

પરીક્ષાના નમૂના જવાબ (પુસ્તકના ઉદાહરણો પ્રમાણે)

નોંધઆ ગુણ પ્રમાણે જવાબ કેવો લખવો તેના થોડા નમૂના છે. સ્વાધ્યાય 8.1, 8.2, "પ્રયત્ન કરો" અને સ્વાધ્યાયપોથી/પ્રેક્ટિસ બુકના બધા ઉકેલ જવાબ-પત્રકમાં આવશે — બંને પુસ્તકો મળ્યા પછી. Maths નો પ્રથમ સત્રાંતનો અભ્યાસક્રમ/પેપર પદ્ધતિ હજી મળ્યાં નથી.
નમૂનો 1 — વ્યાખ્યા
પ્ર. સંમેય સંખ્યા એટલે શું?
જ. જે સંખ્યાને p/q સ્વરૂપમાં લખી શકાય, જ્યાં p અને q પૂર્ણાંક છે અને q ≠ 0, તેને સંમેય સંખ્યા કહે છે. દા.ત. −2/7, 3/8, 3.
નમૂનો 2 — પ્રમાણિત
પ્ર. −45/30 ને પ્રમાણિત સ્વરૂપમાં ફેરવો.
જ. ગુ.સા.અ. (45, 30) = 15. −45/30 = (−45 ÷ 15)/(30 ÷ 15) = −3/2.
નમૂનો 3 — સરવાળો
પ્ર. −2/3 + 3/8 શોધો.
જ. લ.સા.અ. (3, 8) = 24. −2/3 = −16/24, 3/8 = 9/24. સરવાળો = (−16 + 9)/24 = −7/24.
નમૂનો 4 — ભાગાકાર
પ્ર. 4/9 ÷ (−5/7) શોધો.
જ. (−5/7) નો વ્યસ્ત = 7/−5. 4/9 ÷ (−5/7) = 4/9 × 7/−5 = −28/45.

07વાલી માટે

વાલી માટે
  • આકૃતિ 6 ની સંખ્યારેખા કાગળ પર −1 થી 0 દસ ભાગે દોરાવો; −1/2 અને −1/5 બિંદુ કરાવો — કઈ જમણી?
  • સરવાળો-બાદબાકી સંખ્યારેખાથી (આકૃતિ 11–12) બતાવો: ઋણ ઉમેરવું = ડાબે જવું.
  • સામાન્ય ભૂલ: ઋણ ચિહ્ન ગુણાકારમાં ભૂલવું; ભાગાકારમાં પહેલી સંખ્યાનો વ્યસ્ત લેવો; −1/2 vs −1/5 ની સરખામણી ઊલટી.
  • ચિત્ર-પસંદગી (chart audit): સંખ્યારેખા (અંતર ગણીને), નિર્ણય-વૃક્ષ, વિસ્તારનું અંડાકાર ચિત્ર, ફ્લો.
