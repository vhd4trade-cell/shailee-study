Aમુખ્ય મુદ્દા

પાંચ તબક્કા
અંતઃગ્રહણ → પાચન → શોષણ → સ્વાંગીકરણ → મળત્યાગ. પાચન = જટિલ → સરળ ઘટકો.
નોંધમાં જુઓ →
પાચનનળી અને ગ્રંથિ
મુખગુહા → અન્નનળી → જઠર → નાનું આંતરડું → મોટું આંતરડું (મળાશય) → મળદ્વાર. ગ્રંથિ: લાળગ્રંથિ, યકૃત, સ્વાદુપિંડ.
નોંધમાં જુઓ →
કોણ કયો રસ
લાળ → સ્ટાર્ચ → શર્કરા. જઠર: HCl + પાચકરસ → પ્રોટીન. પિત્તરસ → ચરબી. સ્વાદુરસ → ત્રણેય. આંત્રરસ → બધું.
નોંધમાં જુઓ →
પાચનની પેદાશો
કાર્બોદિત → ગ્લુકોઝ; પ્રોટીન → એમિનો ઍસિડ; ચરબી → ફેટિ ઍસિડ + ગ્લિસરોલ.
નોંધમાં જુઓ →
શોષણ અને મળત્યાગ
રસાંકુરો (નાનું આંતરડું) → રુધિરવાહિની. મોટું આંતરડું: પાણી-ક્ષાર; મળ → મળાશય → મળદ્વાર.
નોંધમાં જુઓ →
દાંત
છેદક, રાક્ષી, અગ્રદાઢ, દાઢ; દૂધિયા દાંત 6–8 વર્ષે પડે. સડો: બૅક્ટેરિયા + શર્કરા → ઍસિડ; દિવસમાં બે વાર બ્રશ.
નોંધમાં જુઓ →
વાગોળનાર અને અમીબા
ઝડપથી ગળે → આમાશય → વાગોળ → ચાવે; અંધાંત્રમાં સેલ્યુલોઝ. અમીબા: ખોટા પગ, અન્નધાની, એક કોષ.
