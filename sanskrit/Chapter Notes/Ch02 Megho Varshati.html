00પાઠ એક નજરે

શા માટે ભણવું: વરસાદથી ખેડૂત-ખેતર-પાકની સાંકળ: ક્રિયાપદ (-ति) ઓળખતાં શીખવતું ટૂંકું કાવ્ય; [2B] માં આ કાવ્યના શ્લોકના અનુવાદ પૂછાય.

આ પ્રકરણ પછી તમે પાઠ વાંચી-બોલી શકશો, દરેક વાક્ય/શ્લોકનો ગુજરાતી અનુવાદ કહી શકશો, શબ્દાર્થ યાદ રાખી શકશો અને પરીક્ષાના પ્રશ્નોના જવાબ સંસ્કૃત-ગુજરાતીમાં લખી શકશો.

‘मेघो वर्षति’ — શબ્દ કેવી રીતે જોડાયો?

मेघः + वर्षति → मेघो वर्षति (પુસ્તકનું ‘વિશેષ’). हलम् + अपि → हलमपि. એટલે લખવામાં બે શબ્દ જોડાયેલા દેખાય, બોલવામાં સરળતા.

કાવ્યની સાંકળ

વાદળ વરસે → પાણી વહે → ખેડૂત રાજી → બળદ-હળ → ખેડ → બીજ → પાક → સમૃદ્ધિ અને માનવકુળની વૃદ્ધિ. દરેક પંક્તિ એક ક્રિયા છે.

→ આગળ: અનુવાદ → શબ્દાર્થ → વ્યાકરણ → પરીક્ષાના પ્રશ્નો

01પાઠ અને અનુવાદ

શા માટે ભણવું: શ્લોકના અનુવાદ [2B] અને સંસ્કૃત વાક્યોનો ગુજરાતી અનુવાદ [4A] — બંને સીધા આના પર આધારિત છે.

કાવ્ય — પંક્તિ પ્રમાણે

સંસ્કૃતગુજરાતી અનુવાદ
मेघो वर्षतिવાદળ વરસે છે,
प्रवहति नीरम् ।પાણી વહે છે.
तुष्यति कृषकःખેડૂત સંતુષ્ટ (રાજી) થાય છે,
गच्छति गोष्ठम् ॥(તે) પશુઓના વાડા તરફ જાય છે.
नयति च वृषभंઅને બળદને લઈ જાય છે,
हलमपि वहति ।હળ પણ ઉપાડી જાય છે.
कर्षति क्षेत्रंખેતર ખેડે છે
वपति च बीजम् ॥અને બીજ વાવે છે.
रोहति सस्यंધાન્ય (પાક) ઊગે છે,
फलति प्रकामम् ।પુષ્કળ ફળે છે.
भवति समृद्धिःસમૃદ્ધિ થાય છે
मनुकुलवृद्धिः ॥અને માનવકુળની વૃદ્ધિ (આબાદી) થાય છે.

નોંધ: પુસ્તકમાં ‘मनुकुलवृद्धिः’ છપાયેલું છે — પરીક્ષામાં પુસ્તક મુજબ જ લખો. કવિ: महाबलेश्वरभट्टः.

03વ્યાકરણ / ભાષાસજ્જતા

શા માટે ભણવું: નિયમ સમજ્યા પછી નવાં વાક્યો જાતે બનાવી શકાય — રટવું ઓછું પડે.

ક્રિયાપદ ઓળખવાની રીત: કાવ્યનાં ઘણાં શબ્દો -ति થી પૂરા થાય છે — એ ક્રિયાપદ (વર્તમાનકાળ, ‘તે … છે/કરે છે’).

04પરીક્ષાના પ્રશ્નો

શા માટે ભણવું: દરેક પ્રશ્ન-પ્રકારની પ્રૅક્ટિસ — પેપર જેવી જ રીતે.

નોંધનીચેના પ્રશ્નો અમે બનાવેલા નમૂના છે (પાઠ્યપુસ્તકના સ્વાધ્યાયના પ્રશ્નો નથી). સ્વાધ્યાય-સ્વાધ્યાયપોથી-પ્રૅક્ટિસ બુકના જવાબ, તે ત્રણે મળ્યા પછી જ બનશે. પેપર-પદ્ધતિ (80 ગુણ): 1A વિકલ્પ [10] · 1B ✓/✗ [10] · 2A ખાલી જગ્યા [10] · 2B શ્લોકનો અનુવાદ [10] · 3A ગુજરાતીમાં જવાબ (ગમે તે 5) [10] · 3B સંસ્કૃતમાં જવાબ (ગમે તે 5) [10] · 4A અનુવાદ [10] · 4B સમાનાર્થી [5] · 4C અર્થ [5].

05સારાંશ — યાદ રાખો

શા માટે ભણવું: છેલ્લી ઘડીએ એક નજરમાં પુનરાવર્તન.

યાદ રાખો
  1. કાવ્યની સાંકળ: વાદળ → પાણી → ખેડૂત → બળદ-હળ → ખેડ → બીજ → પાક → સમૃદ્ધિ.
  2. -ति = ક્રિયાપદ (તે કરે છે): वर्षति, कर्षति, वपति, रोहति, फलति.
  3. विशेष: मेघः+वर्षति = मेघो वर्षति; हलम्+अपि = हलमपि.
  4. કવિ: મહાબલેશ્વરભટ્ટ.
વાલી માટેબાળક પાસે કાવ્ય ગવડાવો અને દરેક પંક્તિ ખેડૂતની ક્રિયા તરીકે અભિનય કરાવો.
